# AI Chat Exporter 1.4.2

## 中文

### 修复

- 修复 Claude 上传的文本文件（例如 `.txt`、`.md`）在导出中丢失的问题（Issue #25）。现在读取消息的 `attachments[]`，文件名显示在所属消息下；只有附件、没有输入文字的用户消息也会保留，不再造成两条 AI 回复相邻。
- 开启上传文件与 artifact 导出时，API 提供的提取正文会作为文档附在导出末尾；未提供正文时仅保留文件名，不额外下载原文件。关闭“包含上传文件”会同时隐藏文件引用和提取正文，不删除原用户消息。

### 页面快照与恢复（Issue #19）

- 普通导出无法验证完整历史时自动保存带范围声明的页面快照；PDF 转交稳定预览页，不在短暂弹窗里生成。切换或重载来源页、取消捕获时不下载旧结果，取消或仅打开预览不显示“导出成功”。
- 恢复草稿可选保留 7/30/90 天或直到手动删除；默认每条 1 MiB、总量 4 MiB。恢复页面可主动启用扩展本地存储，授权后移除应用字节上限，仍最多 20 条，受磁盘和浏览器限制。Chrome/Edge 运行时请求可选权限；Firefox 安装时声明该权限，但应用内仍需主动开启。
- 不再为腾空间静默删除未过期的已停止/暂停草稿；配置读取失败不触发七天清理。撤销权限或恢复默认限额保留旧草稿，超限新写会暂停。恢复页可直接下载 Markdown，大草稿无需经过 1 MiB 临时预览缓存。
- 这些改进不让历史关闭的会话自动出现在定时/批量导出中；本地恢复仍仅支持 Gemini、默认关闭，重启浏览器后不会自行恢复保护。

### 其他修复与改进

- HTML/PDF 保留 Python、YAML、Makefile 代码块的缩进、Tab 和空行，不再把连续空格压成一个空格。
- 识别 ChatGPT API 的图片指针，保留纯图片消息；无法取得图片 URL 时明确标注图片不可用，不再静默遗漏。当前页准确匹配的图片可补入；不下载私有图片句柄，批量导出不承诺恢复原图。
- 卸载后可打开中英双语反馈页，原因可多选、说明可选填；用户可选择通过邮件草稿发送（无需 GitHub 账号），或前往 GitHub 确认发布公开 issue（需要账号），不自动提交、无统计追踪。弹窗与设置新增帮助入口。
- 按语言统一标题、正文、按钮、输入框、下拉框和反馈页的衬线字体：英文/德文沿用 Iowan/Palatino 风格，中文用宋体、日文用明朝体、韩文用明朝系回退；代码和公式保留专用字体。补齐德/日/韩常用设置及文件名编辑翻译；修复窄窗口设置页的标题挤压和开关拉伸。

本版本尚未发布到商店。附件回归使用 Issue #25 公开脱敏结构构造的合成数据，未对登录态 Claude 或 Firefox/Edge 运行时进行验收。

## English

### Fixes

- Fix missing Claude uploaded text files such as `.txt` and `.md` (issue #25). Message-level `attachments[]` are now read, filenames stay on their original turns, and upload-only user turns are retained instead of leaving consecutive assistant replies.
- With uploaded files and artifact export enabled, provider-extracted text is included as document artifacts at the end of the export. Files without extracted text retain their names; no additional file downloads are made. Disabling uploaded files hides both references and extracted text without deleting the user turn.

### Page snapshots and recovery (issue #19)

- Unverified regular exports fall back to labelled page snapshots; PDF is handed to a stable preview tab rather than generated in a transient popup. Navigation, reload and cancellation discard stale captures. Cancellation and opening a preview do not report a completed export.
- Recovery retention is configurable: 7/30/90 days or until deletion. Defaults remain 1 MiB per draft and 4 MiB total. Explicit expanded-storage opt-in plus the browser permission removes application byte limits, retaining the 20-draft limit and real browser/disk constraints. Chrome/Edge request an optional permission; Firefox declares it at installation but still requires application opt-in.
- Storage pressure no longer evicts unexpired stopped/paused drafts. A settings-read failure cannot trigger seven-day expiry. Revocation or returning to default limits keeps existing drafts and may pause new writes. Recovery can save Markdown directly, bypassing the 1 MiB temporary preview cache.
- This does not add history-off conversations to bulk/scheduled export. Local recovery remains Gemini-only, off by default, and paused after browser restart.

### Further fixes and improvements

- Preserve exact indentation, tabs and blank lines in fenced code for HTML/PDF exports.
- Recognize ChatGPT image pointers and retain image-only turns. Images without usable URLs are labelled unavailable rather than silently omitted. Confidently matched rendered images can enrich the current conversation; private handles are not downloaded and batch exports do not promise to recover original images.
- Add an optional bilingual uninstall feedback page with selectable reasons and free text. Choose an email draft (no GitHub account needed) or a public GitHub issue draft for review (account required); no automatic submission or analytics. Add help links to popup and settings.
- Use consistent locale-aware serif typography for headings, body, controls and feedback: Iowan/Palatino for Latin text, Songti for Chinese, Mincho for Japanese and Korean serif fallbacks. Preserve specialized code/math fonts and complete common German/Japanese/Korean settings translations. Fix squeezed schedule headings and stretched toggles in narrow settings windows.

Not yet published to extension stores. Attachment regressions use synthetic data based on the public redacted shape in issue #25, not a logged-in Claude capture. Logged-in Claude and Firefox/Edge runtime acceptance remain unverified.
